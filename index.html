Privacy Policy for N-gram SEO Analyzer

1. Overview

The N-gram SEO Analyzer Chrome Extension analyzes visible text on the webpage the user is currently viewing and generates N-gram frequency data. All processing is performed locally within the user's browser.

2. Data Collection

This extension does not collect, store, transmit, or share any user data. It does not access personal information, browsing history, analytics, or cookies.

3. Use of Permissions

The extension uses permissions such as activeTab and scripting solely to extract visible text from the webpage the user explicitly chooses to analyze. The extension does not alter the page or transfer data externally.

4. Local Processing

All N-gram analysis is done directly in the user's browser. No data is sent to external servers, and no backend services are involved.

5. Third-Party Services

The extension does not use any external APIs, third-party analytics, tracking scripts, or remote code.
